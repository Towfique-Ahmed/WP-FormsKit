The premium add-on for WP FormsKit. Conditional logic, multi-step forms, file uploads, reCAPTCHA, integrations and Stripe payments — every free feature included.

== Description ==

WP FormsKit Pro is an **add-on** for the free WP FormsKit plugin. Install and
activate WP FormsKit first, then WP FormsKit Pro layers on advanced features
without changing anything you already built.

= Everything in Free, plus =

* **Conditional logic** — show or hide fields based on what the visitor enters.
* **Multi-step forms** — split long forms into pages with an optional progress bar.
* **File upload field** — collect files straight into the Media Library.
* **Advanced fields** — star rating, range slider, password, section divider, page break, payment.
* **reCAPTCHA v3** — score-based spam blocking that verifies server-side.
* **Integrations** — outgoing webhooks, Slack notifications, Mailchimp subscribe.
* **Stripe payments** — collect payments via Stripe Checkout on submit.
* **License management** — keys and automatic updates.

== Installation ==

1. Install and activate **WP FormsKit** (the free plugin).
2. Upload and activate **WP FormsKit Pro**.
3. Go to **FormsKit → License** to activate your key.
4. New field types and settings appear automatically in the form builder.

== Requirements ==

* WP FormsKit 1.0.0 or later (free plugin) — required.
* WordPress 6.0+, PHP 7.4+.
